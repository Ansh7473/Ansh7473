### 👨‍💻 About Me
I'm a senior AI engineer, Web3 developer, and automation enthusiast focused on building high-performance proxy gateways, AI-driven developer tooling, and customized media scraping dashboards. I solve hard problems like LLM rate limits, token waste, and local service orchestration.

- 🚀 **Core Focus**: Developing latency-optimized routers, token compression engines, and edge deployment automation.
- 🛠️ **Expertise**: Node.js/Next.js, Python/FastAPI, Solidity, Rust, and containerized deployment (Docker).
- 🧬 **Latest Obsession**: Smart streaming mocks, Cloudflare workers pools, and low-latency API proxy gateways.
- 🎯 **Philosophy**: "Build tools that make AI cheaper, faster, and accessible without limits."

### ⚡ Latest Contributions & Active Work
Here is a detailed breakdown of my recent contributions and active engineering work across my primary repositories:

#### 🧠 [9Router - FREE AI Router & Token Saver](https://github.com/Ansh7473/9router)
*A universal AI router that connects any coding tool to 40+ providers, featuring RTK lossless token compression for 20-40% token savings.*
* ⚡ **AI Speedtest Engine (`feat(speedtest)`)**: Designed and implemented a real-time latency and Transactions Per Second (TPS) checking module with gorgeous, glowing reactive UI panels. Integrated strict exclusions for developer companions like `Antigravity` and `Codex`.
* 🌐 **Edge Proxy Deployer**: Integrated direct Cloudflare Workers edge deployer and proxy pooling to seamlessly distribute requests globally.
* 🔄 **OpenAI ↔ Claude Translation**: Optimized translation layer by parsing and stripping empty "Read pages" system arguments from Claude CLI interactions to prevent translation aborts.
* 🎨 **Component Optimization**: Fixed React `setState` loop race conditions within live metric-tracking dashboard graphs.

#### 🎬 [yt-dlp Web UI (dlp)](https://github.com/Ansh7473/dlp)
*A feature-rich command-line audio/video downloader transformed into a premium self-hosted Web UI dashboard.*
* 🔄 **Stream & Signal Mocks**: Created robust mock streams and unhandled exception hook setups for stable backend serving.
* 🛡️ **Daemon Orchestration & Auto-Kill**: Implemented automated background socket checks to auto-kill stale processes on port `8000` when spinning up the FastAPI server, ensuring zero port conflicts.
* 📦 **PyInstaller Packaging Pipeline**: Engineered a zero-dependency PyInstaller packaging process, resolving `uvicorn` logging failures under no-console daemon modes, and compiling the FastAPI backend into a single executable.
* 🍪 **Advanced Cookies Interface**: Added a top-level reactive settings menu and a slick copy-paste modal interface for raw `cookies.txt` data to seamlessly bypass extraction rate limits.
